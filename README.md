# 使照勘驗缺失照片自動匯入工具

把工地現場拍的缺失改善照片，依編號自動對應到「使照勘驗缺失紀錄表.xlsx」，
每個缺失（或每組缺失）產生一個分頁，並在主表加上可點擊的照片連結。

- 原始 Excel 檔案**不會被覆蓋**，一律另存成 `使照勘驗缺失紀錄表_含照片_YYYYMMDD.xlsx`
- 可以**每次勘驗後重新執行**，重複執行不會把分頁越跑越多
- 照片會自動壓縮、校正直式/橫式方向，避免檔案爆掉或照片躺平

---

## 一、安裝（Windows）

### 1. 安裝 Python

到 [python.org](https://www.python.org/downloads/) 下載安裝 **Python 3.10 以上版本**。
安裝時務必勾選「**Add python.exe to PATH**」。

安裝完成後，開啟「命令提示字元」（cmd）或 PowerShell，輸入以下指令確認：

```bat
python --version
```

### 2. 安裝所需套件

把本工具的資料夾（含 `build_photo_report.py`、`requirements.txt`）放到你習慣的位置，
例如 `C:\使照勘驗工具\`，然後在該資料夾內開啟命令提示字元，執行：

```bat
pip install -r requirements.txt
```

這會安裝：
- `openpyxl`：讀寫 Excel 檔案
- `Pillow`：照片縮圖、壓縮、校正方向

> **如果照片有 HEIC/HEIF 格式（iPhone 預設拍照格式）**，請額外安裝：
> ```bat
> pip install pillow-heif
> ```
> 沒裝這個套件時，程式遇到 HEIC 照片會**明確報錯並告訴你要裝什麼**，不會偷偷跳過不處理。

## 二、照片資料夾怎麼擺

在「使照勘驗缺失紀錄表.xlsx」**同一個資料夾**下，建立一個名為 `照片` 的資料夾，
裡面依主表的「編號」欄位（D-001、D-002...）建立子資料夾：

```
我的工地資料夾/
├── 使照勘驗缺失紀錄表.xlsx
├── build_photo_report.py
└── 照片/
    ├── D-001/
    │   ├── 改善前/
    │   │   ├── IMG_1234.jpg
    │   │   └── IMG_1235.jpg
    │   └── 改善後/
    │       └── IMG_1301.jpg
    ├── D-002/                  ← 沒有子資料夾，照片直接放這裡
    │   ├── IMG_2001.jpg        ← 一律視為「改善前」
    │   └── IMG_2002.png
    └── D-003/                  ← 主表有這筆缺失，但這裡還沒放照片也沒關係
```

規則整理：

| 情況 | 結果 |
|---|---|
| 資料夾內有「改善前」「改善後」子資料夾 | 分別歸類 |
| 資料夾內沒有子資料夾，直接放照片 | 全部視為「改善前」 |
| 主表有這筆缺失，但找不到對應資料夾 | 不建立分頁，執行報告中會列出提醒 |
| 有資料夾、資料夾裡沒有支援格式的照片 | 不建立分頁，報告中會列出提醒 |
| 資料夾存在，但主表查無此編號（打錯字、孤兒資料夾） | 跳過該資料夾，報告中會警告，不會中斷執行 |

支援格式：`.jpg` `.jpeg` `.png` `.heic` `.heif`

## 三、怎麼執行

在工作資料夾內開啟命令提示字元，直接執行：

```bat
python build_photo_report.py
```

這會自動讀取同資料夾下的 `使照勘驗缺失紀錄表.xlsx` 與 `照片/`，
輸出 `使照勘驗缺失紀錄表_含照片_20260101.xlsx`（日期為執行當天）。

也可以指定檔案路徑（例如檔案不在同一個資料夾、或檔名不同）：

```bat
python build_photo_report.py "D:\工地A\紀錄表.xlsx" "D:\工地A\照片"
```

指定輸出檔案名稱：

```bat
python build_photo_report.py --output "D:\工地A\本週報告.xlsx"
```

執行完成後會印出摘要，例如：

```
========================================================
使照勘驗缺失照片匯入工具 - 執行摘要
========================================================
來源檔案：使照勘驗缺失紀錄表.xlsx
照片資料夾：照片
--------------------------------------------------------
缺失總數（E欄有值）：23 筆
找到照片並建立分頁的缺失：19 筆
有效照片總數：52 張
分頁建立方式：逐項建立（每個缺失一個分頁）
--------------------------------------------------------
照片壓縮：原始總容量 148.32 MB → 壓縮後 9.84 MB （節省 93.4%）
--------------------------------------------------------
⚠ 警告（2 項）：
  - D-012：找不到對應照片資料夾，未建立分頁。
  - 資料夾「D-099」在主表查無對應編號，已忽略。
❌ 錯誤（0 項）：
--------------------------------------------------------
輸出檔案：使照勘驗缺失紀錄表_含照片_20260101.xlsx
========================================================
```

**每次勘驗完、照片更新後，重新執行一次即可**，輸出檔會以最新資料重新產生
（分頁不會重複增生，但也別忘了每次都輸出成新檔案，原始檔永遠保持乾淨）。

## 四、分頁數量過多時怎麼辦

如果有照片的缺失項目超過 **60 項**（可在 `build_photo_report.py` 檔案開頭的
`MAX_INDIVIDUAL_SHEETS` 常數調整），程式會自動改成**依查驗項目分組**，
一組一個分頁、組內多個缺失依序排列，避免 Excel 分頁太多卡死或檔案過大。
執行時會印出提醒，告訴你目前是用哪種方式產生分頁。

## 五、驗證測試（開發者/進階使用）

`tests/generate_test_data.py` 可以自動產生一份測試用的 Excel + 假照片資料夹，
方便在不動用真實資料的情況下驗證工具是否正常運作：

```bat
:: 產生涵蓋四種狀態、EXIF旋轉、照片壓縮、各種例外情況的精選測試資料
python tests\generate_test_data.py

:: 產生 65 筆缺失資料，測試「超過60項改用分組分頁」的邏輯
python tests\generate_test_data.py --rows 65 --photos-per 2

:: 產生 50 筆缺失 x 每筆 3 張照片，對應驗收標準的容量情境（輸出應 < 50MB）
python tests\generate_test_data.py --rows 50 --photos-per 3
```

產生後，資料會放在 `tests/sample_data/`（或指定的 `--out` 資料夾），
進入該資料夾執行 `python ..\..\build_photo_report.py` 即可測試。

## 六、常見問題

**Q: 直式照片在 Excel 裡變成橫躺的？**
A: 本工具會先讀取照片的 EXIF 方向資訊校正後再存檔，正常情況不會躺平。
如果還是躺平，請確認照片本身的 EXIF 資訊是否正確（部分截圖工具、通訊軟體轉傳
的照片可能已經遺失 EXIF 資訊，這種情況無法自動判斷原始方向）。

**Q: 輸出的 Excel 檔案太大？**
A: 預設長邊縮到 1600px、JPEG 品質 80、單張目標 300KB 以內，一般情況下
50 筆缺失 × 3 張照片的輸出檔會在數 MB 到數十 MB 之間。如果還是太大：
- 檢查照片資料夾裡是否混入了非常大量或超高解析度的照片
- 可調整 `build_photo_report.py` 開頭的 `MAX_DIMENSION`（縮小一點，例如 1200）
  或 `TARGET_MAX_BYTES`（壓更小，例如 200KB）

**Q: 某個缺失項目沒有生成分頁？**
A: 檢查執行後印出的「警告」清單，通常是以下原因之一：
1. `照片/` 底下找不到對應編號的資料夾（資料夾名稱要完全等於編號，例如 `D-001`）
2. 資料夾存在，但裡面沒有支援格式（jpg/jpeg/png/heic/heif）的照片
3. 資料夾裡的照片全部損毀或無法讀取（請看「錯誤」清單，會列出具體檔名與原因）

**Q: 出現「找不到 HEIC 解碼套件」錯誤？**
A: 執行 `pip install pillow-heif` 後再試一次。

**Q: 執行時提示「無法寫入輸出檔案」？**
A: 代表輸出檔案目前被 Excel 開著，請先關閉該檔案再重新執行。

**Q: 我可以把輸出檔案當作下次執行的來源檔案嗎？**
A: 可以，程式在產生新分頁前會先清除上次自動產生的照片分頁（D-xxx / G-xxx），
原始的 4 個分頁（勘驗紀錄/統計/查驗項目參考/選單）永遠不會被清除或覆蓋格式，
所以不論你是對原始檔案還是對上次的輸出檔案重新執行，都不會重複增生分頁。

## 七、檔案結構（相容性說明，不應手動修改）

本工具只會：
1. 新增（覆蓋重建）以 `D-` 或 `G-` 為名稱開頭的照片分頁
2. 在「勘驗紀錄」分頁新增 **M 欄（照片）**，寫入可點擊的照片連結

以下內容**完全不會被改動**：
- 「勘驗紀錄」分頁原有的 A~L 欄公式、格式、資料驗證（D/J 欄下拉選單）、
  條件式格式（K 欄狀態上色、逾期整列變紅）
- 「統計」「查驗項目參考」「選單」三個分頁

## 八、VBA 巨集版本？

目前以 Python 版本為主（跨平台、好維護、好除錯），VBA 巨集（.xlsm）版本
目前**未提供**。若日後有「不想安裝 Python」的需求，可以再另外開發，
但建議先以 Python 版本搭配 `pip install -r requirements.txt` 使用，
安裝一次後不需要每次重新設定。

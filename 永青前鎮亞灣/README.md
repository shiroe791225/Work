# 永青前鎮亞灣｜每日工作待辦

單一檔案網站（`index.html`），用來記錄每日工作待辦，並為每項待辦附上照片與「照片用意」說明。

## 功能
- 依日期記錄待辦（◀ ▶ 切換日期、「今天」快速返回）
- 優先度（高／中／低）、備註、完成勾選（記錄完成時間）、完成進度條
- 每項待辦可附多張照片，每張照片必填「用意說明」；未填會以紅字提示
- 照片說明快捷標籤：待改善、缺失追蹤、查驗紀錄、需會同監造、材料進場、安全衛生、工程變更、請廠商處理
- 前一天未完成事項可一鍵「帶入今天」（照片一併帶入）
- 跨日期搜尋（待辦、備註、照片說明）
- 匯出／匯入 JSON 備份（含照片，檔名 `yongqing-todo-backup-YYYY-MM-DD.json`）
- 手機可直接拍照上傳；照片自動壓縮（長邊 1600px）節省空間

## 使用方式
1. 直接用瀏覽器開啟 `index.html` 即可使用；或
2. 啟用 GitHub Pages（Settings → Pages → 選擇分支與根目錄），網址為
   `https://shiroe791225.github.io/Work/永青前鎮亞灣/`

## 注意事項
- 資料存在**目前這台裝置的瀏覽器**（IndexedDB），不會上傳到 GitHub，也不會在手機與電腦間自動同步。
- 清除瀏覽器資料會一併清除紀錄 → **請定期「匯出備份」**，換裝置時用「匯入備份」搬移。
- GitHub Pages 對私有 repo 需付費方案；免費帳號請將 repo 設為 public，或直接開啟本機檔案使用。
